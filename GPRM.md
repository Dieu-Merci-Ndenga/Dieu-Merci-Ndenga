Crée le repo pour ton profil GitHub :<br>- Va sur GitHub.com, clique "New Repository".<br>- Nom : exactement ton-nom (remplace par ton username réel, e.g., alex-dev).<br>- Description : "Mon profil GitHub avec README et projets full-stack 2026".<br>- Public : Oui.<br>- Initialise avec README : Non (on le fait manuellement).<br>- Clique "Create repository".<br><br>2. Clone et ajoute le README GPRM :<br>- Terminal :<br>     git clone https://github.com/ton-nom/ton-nom.git<br>     cd ton-nom<br>     <br><br>- Crée README.md avec le contenu ci-dessus (copie-colle dans un éditeur comme VS Code).<br>- Ajoute et push :<br>     git add README.md<br>     git commit -m "Add GPRM README"<br>     git push origin main<br>     <br><br><br>3. Active GitHub Pages pour ta première page :<br>- Va sur le repo GitHub > Settings > Pages.<br>- Sous "Build and deployment", Source : Sélectionne "Deploy from a branch".<br>- Branch : Sélectionne main et folder : / (root).<br>- Clique "Save".<br>- Attend 1-2 minutes. Ta page sera à https://ton-nom.github.io (remplace ton-nom par ton username).<br>- Pour vérifier : curl https://ton-nom.github.io dans terminal – doit retourner ton README HTML.<br><br>4. Soumets à GPRM pour générer le README optimisé :<br>- Va sur https://gprm.itsvg.in/<br>- Dans le champ "GitHub Username", entre exactement ton-nom (ton username).<br>- Clique "Generate".<br>- Télécharge le README généré (il inclura stats automatiques comme contributions snake, etc.).<br>- Remplace ton README.md dans le repo ton-nom avec ce fichier généré :<br>     git add README.md<br>     git commit -m "Update GPRM README from generator"<br>     git push origin main<br>     <br><br>- Force refresh : Va sur https://ton-nom.github.io – ta première page GitHub est live avec ton profil.<br><br>5. Vérification finale :<br>- Clone le repo fullstack-2026-roadmap séparément pour les projets.<br>- Link les repos dans le GPRM README (comme fait ci-dessus).<br>- Si GIF manque : Upload profile.gif dans un repo public, copie l'URL brute (e.g., https://raw.githubusercontent.com/ton-nom/assets/main/profile.gif), et remplace dans README.<br><br>Action immédiate : Fais le repo ton-nom et envoie le lien.
